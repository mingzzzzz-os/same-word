# 同词相遇

两个人各自想一个词，同时揭晓。没撞上，就从这两个词继续联想，直到说出同一个词。

## 两种玩法

**两台设备** —— 开一个房间，把链接发给对方，各拿各的手机玩。

**一台设备** —— 两个人传着同一个手机玩，中间有遮挡交接。

## 玩

https://same-word-57483.app.workbuddy.host/?sharecode=TUJXD7EJ3S

手机上打开后可以「添加到主屏幕」，用起来和 App 一样，断网也能玩。

## 玩法说明

1. 先各自想一个词，提交后同时揭晓
2. 没撞上？下一轮各自想一个和这两个词都有关的新词
3. 直到两人说出同一个词，游戏结束

规则上不考知识，也没有标准答案。考的是你们脑子里装的东西，是不是同一套。

- 判定是精确匹配（去空格、全角转半角、去标点后比较），不做语义猜测
- 两个词互为包含关系或字符高度重合时，会提示「几乎一样」，但**不影响判定**
- 上限 15 轮，到顶还没撞上就是「未相遇」结局
- 结算页可以把整局存成一张图

## 技术说明

纯前端页面，联机部分用 WorkBuddy 云服务的数据库：

- `rooms` 表存房间，`moves` 表存每一轮的提交，`(room_code, round, seat)` 唯一约束防重复提交
- 双方各自提交自己的词，客户端按轮次推导当前状态，不需要服务端状态机
- 同步用 1.5 秒轮询，不做 WebSocket —— 回合制游戏延迟容忍度高，轮询更稳
- 读操作走 PostgreSQL 函数（RPC），避开 GET 请求的缓存问题

## 本地运行

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。也可以直接双击 `index.html`。

本地只能玩单机模式：联机需要后端校验访问来源，只在正式域名下工作。
